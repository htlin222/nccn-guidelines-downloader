# Distant metastasis (M)

- M0, no distant metastasis
    - There is no pathologic M0
    - Use clinical M to complete the stage group
- M1, distant metastasis

# Histologic grade (G)

- GX, grade cannot be assessed
- G1, well differentiated
- G2, moderately differentiated
- G3, poorly differentiated

# Prognostic stage groups

- Stage 0, Tis N0 M0
- Stage I, T1 N0 M0
- Stage II, T2 N0 M0
- Stage III, M0 with any of
    - T1 N1
    - T2 N1
    - T3 N0
    - T3 N1
- Stage IVA, M0 with any of
    - T1 N2
    - T2 N2
    - T3 N2
    - T4a N0
    - T4a N1
    - T4a N2
- Stage IVB, M0 with either of
    - Any T with N3
    - T4b with any N
- Stage IVC, any T, any N, M1
