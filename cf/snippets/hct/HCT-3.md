# Source

- NCCN Hematopoietic Cell Transplantation v3.2026, HCT-3, p11
- Pre-transplant recipient evaluation, the items done only as clinically indicated
- The pre-transplant recipient evaluation generates data to estimate risks of post-transplant complications including NRM, and information that may inform other transplant-related decisions
- For pre-transplant donor evaluation and HLA typing, refer to FACT-JACIE International Standards for Hematopoietic Cellular Therapy Product Collection, Processing, and Administration (8th edition); 2021
- All recommendations category 2A unless otherwise indicated

# Additional clinical assessment, as clinically indicated

- Lumbar puncture for cerebrospinal fluid analysis
- Pregnancy test for individuals of childbearing potential
- Physical therapy evaluation
    - Strength
    - Flexibility
    - Function
- Nutritional evaluation
- Consider geriatric assessment for select patients (category 2B)
    - See NCCN Guidelines for Older Adult Oncology
- Dental evaluation, for allogeneic HCT

# Additional imaging, as clinically indicated

- CT, chest and/or sinuses
    - Chest
    - Sinuses

# Additional laboratory tests, as clinically indicated

- Epstein-Barr virus testing, or other infectious disease testing, if high risk
    - Tuberculosis
    - Strongyloides
    - Human T-cell lymphotropic virus types I and II, for allogeneic HCT
- HLA antibody assessment, if using an HLA-mismatched donor
- 24-hour urine creatinine clearance
    - For borderline renal dysfunction or low muscle mass
- Urine toxicology screen, if history of substance use disorder
- Thyroid-stimulating hormone level
- Iron profile, including ferritin level
- Blood lipid panel
- Vitamin D level
