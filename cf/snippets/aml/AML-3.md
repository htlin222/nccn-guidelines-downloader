# Follow-up bone marrow

- Consider follow-up BM aspirate and biopsy 14–21 days after start of therapy (footnotes f, w, x on AML-3A)
- Read the marrow as one of
    - Residual disease
        - If ambiguous, repeat BM biopsy within 7 days before proceeding with therapy
    - Hypoplasia (footnote y on AML-3A)

# Residual disease, re-induction options

- Cytarabine
- Standard 7 + 3 (daunorubicin or idarubicin) (footnote z on AML-3A)
- 5 + 2, either (daunorubicin or idarubicin) or (mitoxantrone for age ≥60 y) (footnote z on AML-3A)
- Standard 7 + 3 (daunorubicin or idarubicin) + midostaurin (footnote z on AML-3A)
    - For FLT3 mutated, ITD or TKD
- Standard 7 + 3 or 5 + 2 (daunorubicin or idarubicin) + quizartinib (footnote z on AML-3A)
    - For FLT3-ITD only
- HMA (azacitidine or decitabine) + venetoclax (footnotes s, t, u on AML-3A)
- CPX-351, dual-drug liposomal encapsulation of cytarabine and daunorubicin
    - For therapy-related AML other than CBF-AML
    - Or antecedent MDS/CMML
    - Or cytogenetic or molecular changes consistent with MDS
    - Preferred only if given in induction
    - BM aspirate and biopsy 14–21 days after start of therapy
- Consider regimens for relapsed/refractory disease, including targeted therapies, if lack of response to induction
    - Response criteria, see AML-I
    - Therapy for relapsed/refractory disease, see AML-9

# Hypoplasia

- Await recovery
- BM aspirate and biopsy to document remission status (footnote aa on AML-3A)
    - Upon count recovery
    - Or by day 42 at the latest in the setting of delayed count recovery

    - Response criteria, see AML-I
    - Consolidation, if received intensive re-induction (AML-6)
    - Continue lower intensity therapy, if received HMA + venetoclax re-induction (AML-5)

    - Response criteria, see AML-I
    - Allogeneic HCT, see NCCN Guidelines for Hematopoietic Cell Transplantation
    - Cytarabine, if not previously used as treatment for persistent disease at day 15

        - If a clinical trial is not available while awaiting identification of a donor
    - Therapy for relapsed/refractory disease (AML-9)
    - Best supportive care
