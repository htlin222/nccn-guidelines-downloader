# Referral

- Refer to a high-volume multidisciplinary institution for any of the following
    - Bulky disease
    - Locoregional disease
    - Viscerally invasive disease
    - Rapid progression
- Referral includes radiation oncology referral

# Radiation and RAI therapy

- Principles of Radiation and RAI Therapy (THYR-C)
- Dosimetry
    - If considering dosimetry, iodine-131 is the preferred agent
- Pretreatment scan
    - A false-negative pretreatment scan is possible
    - A false-negative pretreatment scan should not prevent the use of RAI if otherwise indicated
